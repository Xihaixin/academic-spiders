# 用户中断程序之后信息丢失

查看当前 localhost 本地数据库，academicdb_test.spider_run_log 表中的数据
你可以发现它的 status 状态有一些显示：interrupted，这个状态表示当程序运行之后，用户手动按下 ctrl + c 之后，项目虽然可以正常关闭，但是 spider_run_log 没有正常记录 request 和 pages 等相关信息。

如果你需要进行测试，那么可以切换开发状态：python env.py switch test

可以看到用户在 09:30:22 发出了一个 shutdown 指令，但是程序仍然没有停止，反而继续运行直到 09:30:25 用户又按下 shutdown 即 ctrl +C ,这意味着什么 ？我后来发现在数据库中 spider_run_log 表中状态 status 显示为 running，但是程序已经停止了。这种情况是为什么 ？
